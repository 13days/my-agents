# 项目优化检查（2026-11-23）

## 本轮落地

- 助理发现接口的分页游标过期后，在原时间窗口清除游标并重试一次；保留消息 ID 去重，不推进未完成水位。实时与历史两条读取链路相互隔离，发现失败后仍尝试选定聊天和补充信息。整体失败仍报错，不伪装成成功。
- 修复 npm 文件白名单遗漏 `feishu-bots.js`。CI 从只检查打包列表改成真正打包、独立目录安装、隔离用户数据启动并检查健康接口和助理增量轮询接口。
- 助理无变化事务不再写盘。写入失败清理临时文件；成功持久化才更新内存状态和版本。
- 助理页面带数据版本轮询；没有变化时只传运行状态。重启后版本改变，客户端会重新取得快照。完整消息分页及数据库迁移尚未做。
- 部署时校验仓库地址及远端工作区，发现脏文件停止更新；从 systemd 读取运行目录。推送失败停止部署，远端合并失败不再被清理命令掩盖。

## 检查边界

运行依赖 `npm audit --omit=dev` 本轮报告 0 个已知漏洞，这不等于完整安全审计。接口已有 Host/Origin/token 统一保护，抓包索引已有 worker，任务记录已有落盘与恢复机制，应在这些基础上改进。

本轮不改变自动分析开关，不删除历史消息，不自动重发无法确认结果的任务。未实施数据库迁移、统一账本、模型健康持久化或全站重构；这些应分别建立验收与迁移计划。

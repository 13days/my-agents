# 助理工作台界面

## 参考与取舍

- [Linear Triage](https://linear.app/docs/triage)：集中处理收件箱，先审阅上下文，再确认、暂缓或忽略。
- [LangChain Agent Inbox](https://github.com/langchain-ai/agent-inbox)：面向需要人工介入的 Agent，呈现待确认行动及依据。该仓库已归档，仅参考交互模式，不引入代码或依赖。

## 页面结构

常用入口始终显示：工作概览、待我确认、消息记录、执行记录、事项、反馈与学习、设置。窄屏导航横向滚动，不把功能藏在“更多”里。

概览保留两个主区：“我查看了什么”和“我的决策与执行”。决策主体直接展开，原始消息、引用证据和纠正表单按需展开。同步错误直接显示，不把读取失败当作没有新消息。

四项指标分别表示待确认建议（含暂缓）、已读取消息、未结束的投递、已完成建议。完成建议与完成投递不是同一种计数。预算说明保留在概览及设置。

切换助理分区复用内存中的快照，不重复请求完整数据。后台仍每十秒刷新运行状态；编辑中的内容不被后台刷新覆盖，出现新版本时提示手动刷新。

设置按消息来源、分析预算、确认通知分区，统一保存。全局选择器使用固定尺寸 SVG 箭头，继续保留键盘操作和原有表单值。

## 任务归属

任务行展示“项目 / 对话标题与短 ID / 第 N 次任务”。同一对话以节点及完整会话 ID 识别，不按标题相似度合并；同一会话的任务序号在状态过滤前计算。历史记录没有会话标题时，以最早保存的任务文本作为可读标识，完整会话 ID 放在链接提示中。序号仅表示现有记录中的顺序。

# 聊天软件接入

在面板「聊天软件」选择飞书 / Lark 或企业微信。两者共用网页中的对话、项目目录与引擎，分别管理机器人凭据和成员权限。

## 企业微信

1. 在企业微信创建智能机器人，在 API 模式下选择长连接，取得 Bot ID 和 Secret。此方式需要机器人创建权限和面板到企业微信公有云的出站 WebSocket 连接。
2. 打开 `/im?channel=wecom`。填入 Bot ID 和 Secret，选择 Codex 或 Claude Code，指定新对话使用的项目文件夹。选择默认目录时使用执行机器的默认目录。
3. 点「保存并连接」，状态变为「已连接」后，由希望担任 Owner 的成员先私聊发送 `/whoami`。首位发消息的人自动成为该机器人的 Owner，可以直接执行任务。打开聊天窗口只触发欢迎语。其他成员可私聊获取 UserID，再由面板管理员添加。
4. 私聊发送文字，或在群里 @机器人发送文字。机器人会先确认收到任务，然后把结果发回原聊天。群里回复的内容对群成员可见。同一位成员在同一个聊天内连续发消息，会续接同一对话；不同成员、群和机器人各自独立。网页「对话」可以查看执行记录、完整输出和待处理的工具授权。

| 消息 | 结果 |
| --- | --- |
| 一段文字 | 将任务提交给所选引擎。已有会话继续使用原引擎和项目。 |
| `/new` | 下一条文字创建新对话，使用当前默认引擎和项目。 |
| `/whoami` | 查看自己的成员 UserID。 |
| `/help` | 查看文字命令。 |

「断开连接」会停止接收和回复；已经提交的工作可在网页对话中查看。Secret 保存后不回显，更换 Bot ID 时需要重新填写。认证被拒绝时核对凭据并重新连接。连接被另一客户端取代时，先关闭另一处连接。普通网络断开会自动重连。集群由持有租约的主面板连接机器人。

排查收不到回复时，在接入页查看最近一次收信的时间、私聊或群聊、任务提交和企微回执。群里需要 @机器人。

安装 my-agents 时会检查并补装飞书 `lark-cli` 和企业微信 `wecom-cli`。查文档、邮件、日程等业务能力时，在执行机器运行 `wecom-cli auth init --manual`，按提示输入已有机器人的凭据。运行 `wecom-cli auth show --status` 查看授权状态，`wecom-cli --help` 查看该身份可用的能力。手机「编辑智能机器人 → 能力简介 → 丰富的 AI 开放能力」可以查看能力说明。 [企业微信 CLI 文档](https://github.com/WecomTeam/wecom-cli/blob/main/docs/cli-reference.md)

长回复会在企业微信的长度上限处截断，完整答复留在网页。当前支持文字任务。助理读取个人飞书聊天、飞书交互卡片以及附件处理有各自的接入和权限范围。 [企业微信官方 Node SDK 和长连接协议示例](https://github.com/WecomTeam/aibot-node-sdk)

## 飞书与 Lark

打开 `/im?channel=feishu`，按页面引导扫码创建或填入已有机器人的应用凭据。飞书支持配对、话题、执行卡片和分享卡。旧的 `/feishu` 链接也能进入。 [飞书卡片与命令](feishu-interaction.md)

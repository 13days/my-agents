# 聊天软件接入

在面板「聊天软件」选择飞书 / Lark 或企业微信。两者共用网页中的对话、项目目录与引擎，分别管理机器人凭据和成员权限。

## 企业微信

1. 在企业微信创建智能机器人，在 API 模式下选择长连接，取得 Bot ID 和 Secret。此方式需要机器人创建权限和面板到企业微信公有云的出站 WebSocket 连接。
2. 打开 `/im?channel=wecom`。填入 Bot ID 和 Secret，在「新对话在哪里执行」选择机器和引擎。目录可以使用机器默认目录、已配置的项目，或点「选择文件夹」浏览该机器。模型默认跟随引擎，也可从该机器可用的模型中选择。启用独立 Git 工作区后，新对话从当前提交开始，已有会话沿用原设置。
3. 点「保存并连接」，状态变为「已连接」后，由希望担任 Owner 的成员先私聊发送 `/whoami`。首位发消息的人自动成为该机器人的 Owner，可以直接执行任务。打开聊天窗口只触发欢迎语。其他成员可私聊获取 UserID，再由面板管理员添加。
4. 私聊发文字或语音，或在群里 @机器人交代任务。机器人会先确认收到任务，然后把结果发回原聊天。群里回复的内容对群成员可见。同一位成员在同一个聊天内连续发消息，会续接同一对话；不同成员、群和机器人各自独立。网页「对话」可以查看执行记录、完整输出和待处理的工具授权。

| 消息 | 结果 |
| --- | --- |
| 文字、语音或引用消息后提问 | 继续当前会话。语音使用企微提供的转写，提问时会带上引用的文字或语音转写。 |
| `/new` 或 `/new 帮我跑测试` | 下一条消息另起对话，也可以直接用默认引擎和项目开始一项新任务。 |
| `/sessions [关键词]` | 列出本人在当前聊天中用过的会话，可搜索最近 30 条记录。每次最多展示 8 条。 |
| `/use 1` | 切换到上次列表的第 1 条。切换本身不会启动任务。 |
| `/status` | 查看当前会话、已知的引擎和机器，以及面板记录的执行状态。 |
| `/whoami` | 查看自己的成员 UserID。 |
| `/help` | 查看文字命令。 |

要从手机接着做终端或网页里的工作，先确认接入页显示的 Owner 身份，再勾选「允许已配对的 Owner 在私聊中查找并接手面板和终端会话」并保存。Owner 私聊发送 `/sessions 项目名`，按返回序号发送 `/use 1`，然后继续提问。群聊和其他成员只会看到本人在该聊天用过的会话。

「断开连接」会停止接收和回复；已经提交的工作可在网页对话中查看。Secret 保存后不回显，更换 Bot ID 时需要重新填写。认证被拒绝时核对凭据并重新连接。连接被另一客户端取代时，先关闭另一处连接。普通网络断开会自动重连。集群由持有租约的主面板连接机器人。

在「最近收信与回复」查看最近 30 条记录的发送人、时间、聊天类型、任务提交与企微回执。记录从升级后开始积累。群里需要 @机器人。

「运行与启动」与飞书共用一份设置。原终端自动接收作用于接收消息电脑上的 Claude Code 用户。macOS 会显示该机适用的防睡眠或面板登录自启选项，每个开关旁标明目标电脑。

安装 my-agents 时会检查并补装飞书 `lark-cli` 和企业微信 `wecom-cli`。查文档、邮件、日程等业务能力时，在执行机器运行 `wecom-cli auth init --manual`，按提示输入已有机器人的凭据。运行 `wecom-cli auth show --status` 查看授权状态，`wecom-cli --help` 查看该身份可用的能力。手机「编辑智能机器人 → 能力简介 → 丰富的 AI 开放能力」可以查看能力说明。 [企业微信 CLI 文档](https://github.com/WecomTeam/wecom-cli/blob/main/docs/cli-reference.md)

长回复会在企业微信的长度上限处截断，完整答复留在网页。附件上传仍需使用网页。助理读取个人飞书聊天、飞书交互卡片以及附件处理有各自的接入和权限范围。 [企业微信官方 Node SDK 和长连接协议示例](https://github.com/WecomTeam/aibot-node-sdk)

## 飞书与 Lark

打开 `/im?channel=feishu`，按页面引导扫码创建或填入已有机器人的应用凭据。飞书支持配对、话题、执行卡片和分享卡。旧的 `/feishu` 链接也能进入。 [飞书卡片与命令](feishu-interaction.md)
